This entry coins a brand-new English word, "miswave", for a small moment everyone knows: waving back at a stranger who was actually waving at the person behind you. The program writes the word and its one-line definition to /output/entry.txt, where a judge model compares it against other coinages on how real the gap is, how cleanly the definition lands, and how natural the word feels.

## Run it

```sh
python3.13 main.py
```
